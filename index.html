Đoạn mã đã sửa
function checkLoad(totalCredits) {

    let msg =
    (totalCredits > 15)
    ? "Đủ tải"
    : "Chưa đủ tải";

    document.getElementById("status").value = msg;

}

  • Sai cú pháp value(msg)
  • Phải sửa thành value = msg
